# نسخه آزمایشی سایت کافه YAX

این پروژه یک نمونه‌ی استاتیک HTML/CSS/JavaScript است و برای انتشار آزمایشی با GitHub Pages آماده شده است.

## انتشار با GitHub Pages
1. وارد GitHub شوید و یک مخزن جدید بسازید؛ مثلاً `yax-cafe`.
2. فایل‌های `index.html`، `style.css` و `app.js` را در ریشه مخزن آپلود کنید.
3. به `Settings` → `Pages` بروید.
4. در بخش `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کنید.
5. Branch را روی `main` و پوشه را روی `/(root)` قرار دهید و Save را بزنید.
6. پس از چند دقیقه، آدرس سایت در همان صفحه نمایش داده می‌شود.

## قابلیت‌های نسخه تستی
- نمایش منو و فیلتر دسته‌بندی
- سبد خرید با ذخیره در مرورگر
- فرم اطلاعات مشتری
- ساخت متن سفارش و باز کردن اشتراک‌گذاری تلگرام
- تست اعلان مرورگر (روی HTTPS و با اجازه کاربر)

## محدودیت مهم
این نسخه بک‌اند ندارد. دکمه سفارش، پیام را برای انتخاب مقصد در تلگرام آماده می‌کند و خودش سفارش را مستقیماً برای صاحب کافه نمی‌فرستد. برای ارسال خودکار به تلگرام، ورود واقعی، ذخیره سفارش‌ها و اعلان قابل اتکا در زمان بسته بودن سایت، باید یک بک‌اند امن و پایگاه داده اضافه شود. توکن ربات تلگرام را هرگز داخل فایل‌های سمت کاربر یا مخزن عمومی GitHub قرار ندهید.

تصاویر محصولات از Unsplash بارگذاری می‌شوند و برای نمایش آن‌ها اینترنت لازم است.
